# البحري — الأصناف

تطبيق ويب PWA احترافي لإدارة الأصناف والمخزون، عربي RTL بالكامل، يعمل بدون اتصال ثم يزامن سحابيًا.

## الميزات
- CRUD كامل للأصناف مع صلاحيات مدير/موظف.
- بحث عربي ذكي (تطبيع الهمزات والتاء المربوطة والأرقام العربية).
- فلاتر رقمية متقدمة: `100 | >100 | >=100 | <100 | 100-500`.
- مسح Barcode بالكاميرا (مستمر).
- إنشاء QR ومشاركة عبر Web Share.
- جرد مخصص للجوال مع حفظ تلقائي.
- استيراد/تصدير CSV بترميز UTF-8 و Windows-1256.
- تخزين محلي كامل عبر IndexedDB.
- مزامنة سحابية عبر Firebase Firestore (اختياري) مع Offline.
- وضع داكن/فاتح، Safe Area، Bottom Navigation.
- سجل عمليات (Audit Log) ونسخ احتياطي/استعادة JSON.
